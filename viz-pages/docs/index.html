pairwise-sorter

Rank anything by answering “which is better?” one pair at a time — about n·log₂n questions instead of every pair, and adding an item later costs only ~log₂n more. A TypeScript logic core for Node and the browser, and web components that drop into any page.
Open the sorter app API reference GitHub

How it asks

Binary insertion with you as the comparator. Each item is slotted into the list already placed by halving the gap it could go in. Step through it — this trace was recorded by running the library's own sortIndices on eight coffees.

Why it's cheap

Questions needed to rank n items. Comparing every pair grows with n², binary insertion with n·log₂n — and because it is append-stable, adding one more item only replays old answers and asks ~log₂n new ones.

What's in the box

One package, two entry points. The core is plain logic that runs anywhere and never stores anything itself; the elements are views over a shared Sorter. Click any box.

Use it

Installed straight from GitHub; a prepare script builds it on install. Bun skips dependency build scripts unless you trust the package, so Bun users list it in trustedDependencies. 

npm i github:RascalTwo/pairwise-sorter
# or: bun add github:RascalTwo/pairwise-sorter   (+ "trustedDependencies": ["@rascaltwo/pairwise-sorter"])

The core, anywhere

import { Sorter, emptyList, item } from "@rascaltwo/pairwise-sorter";

const s = new Sorter({ ...emptyList("Coffee"),
  items: ["Flat white", "Mocha", "Cold brew"].map((t) => item(t)) });
s.addEventListener("change", () => save(s.list));

await s.settled();
while (s.question) {
  const { a, b } = s.question;          // indices into s.list.items
  await s.answer(await ask(a, b));      // -1 · 0 · 1
}
s.ranking();   // [{ rank, tied, item }]

The whole app, one tag

<script type="module">
  import "@rascaltwo/pairwise-sorter/element";
</script>

<!-- in memory; add storage-key to keep it -->
<pairwise-sorter storage-key="my-lists"></pairwise-sorter>

Or just the parts you want

const s = new Sorter(list);
for (const el of document.querySelectorAll(
  "pairwise-compare, pairwise-ranking")) el.sorter = s;

Events

question · change · done · upcoming on a Sorter: a pair is waiting · the list changed, save it · a full ranking is ready · items that may be asked next (preload their media)
pairwise-change on <pairwise-sorter>, detail {library} — every list, after any change
pairwise-edit from compare, ranking and bench, detail {index} — an item's edit button
pairwise-stop from <pairwise-progress> — “see the list” once half the items are placed
